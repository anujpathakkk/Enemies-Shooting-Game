## 📌 About the Game

**Enemies Shooting Game** is a colorful and challenging 2D shooting game developed using **C++ and Windows API (WinAPI)**.

The player controls a gun using the mouse and shoots different types of enemies. As the levels increase, enemies become faster and stronger, making the game more challenging.

The game includes multiple weapons, ammunition, reloads, grenades, power-ups, different enemy types, boss battles, combo scoring, and a high-score system.

The project was developed to practice **C++ programming, game logic, event handling, graphics, collision detection, and Windows programming**.

---

## ✨ Features

### 🔫 Multiple Weapons
Choose between different weapons with different shooting characteristics:

- 🟢 Pistol
- 🔵 Rifle
- 🟠 Shotgun
- 🔴 Sniper

Each weapon has different damage, shooting speed, and bullet behaviour.

### 👾 Different Enemy Types

The game contains different enemies with different characteristics:

- 👤 **Normal Enemy** – Standard enemy
- ⚡ **Fast Enemy** – Moves at high speed
- 🛡️ **Tank Enemy** – Has higher health and requires multiple hits
- 👹 **Boss Enemy** – Powerful enemy appearing in higher levels

### 🎯 Mouse Aiming & Shooting

- Aim the gun using the mouse.
- Shoot enemies by clicking.
- The gun rotates according to the mouse position.
- Shooting includes muzzle flash and recoil animation.

### 💥 Grenades

Use grenades to attack multiple enemies at the same time.

### ❤️ Power-Ups

Collect power-ups during the game to improve your chances of survival.

Power-ups include:

- ❤️ Health
- 🔫 Extra Ammo
- 🛡️ Shield
- ⚡ Rapid Fire

### 🔄 Reload System

The game contains a limited ammunition system.

Press:

`R`

to reload your weapon.

### 🏆 Score & Combo System

Earn points by defeating enemies.

Successful attacks can increase your **combo**, allowing you to achieve higher scores.

### 📈 Increasing Difficulty

Every level introduces a greater challenge.

Enemies can become:

- Faster
- Stronger
- More difficult to defeat
- More numerous
- More unpredictable

### 👹 Boss Battles

Boss enemies appear at higher levels and require more shots to defeat.

### 💾 High Score

The game saves the player's best score using:

`highscore.txt`

### ⏸️ Pause System

Press:

`P`

to pause or continue the game.

### 🎨 Colorful Graphics

The game uses colorful programmatically drawn graphics, including:

- Enemies
- Weapons
- Bullets
- Explosions
- Power-ups
- Health bars
- Game background
- HUD elements

No external image assets are required.

# 📊 Game Levels

The game becomes progressively more challenging as the player moves through different levels.

### Level 1 – Fast Start ⚡
Fast-moving enemies introduce the player to the game.

### Level 2 – Rapid Attack 🔥
Enemies move even faster and require quicker aiming and shooting.

### Level 3 – Armored Enemies 🛡️
Stronger enemies with higher health appear.

### Level 4 – Chaos Wave 💥
Different enemy types appear together with unpredictable movement.

### Level 5 – Boss Battle 👹
A powerful boss appears along with supporting enemies.

### Higher Levels 🚀
Enemy speed, health, quantity, and difficulty continue to increase.
